Common traps to get right

These distinctions will help you handle follow-up questions confidently:
Topic	Accurate answer to remember
Private endpoint	It provides a private network interface and IP for accessing a supported service. It does not move that service into your subnet.
Public access after creating a private endpoint	Review and configure public access separately; creating the endpoint alone does not necessarily close public access.
Private DNS zone	It is linked to VNets for resolution; it does not sit inside a subnet.
Private network connectivity	It supplies a network path. The application still needs valid authentication and authorization.


Microsoft’s Private Link and Storage documentation explain these endpoint and access distinctions. Microsoft Learn
Topic	Accurate answer to remember
Azure Load Balancer	Layer 4 traffic distribution; URL-based routing belongs to an application-layer component.
Application Gateway	Regional application-layer web traffic handling.
Front Door	Global application-layer delivery and routing.
Traffic Manager	DNS-based routing; application requests do not pass through it as a proxy.


These are different tools with different traffic-handling models. Azure Architecture Center
Topic	Accurate answer to remember
Contributor	Can manage resources but generally cannot assign Azure roles.
Resource management access	Does not automatically grant every data-plane permission.
Role assignment	Principal + role definition + scope.
RBAC	Determines what an identity is authorized to do.
Azure Policy	Evaluates and enforces resource configuration rules.


Be especially clear about resource management permissions versus permissions to read secrets or blob data. learn.microsoft.com

One current networking detail: do not assume a newly created VM automatically has outbound internet access. New VNets created using API versions released after March 31, 2026 default to private subnets; plan an explicit outbound method such as NAT Gateway. Existing VNets are not automatically changed by that default. Virtual Network
